# Data Mining dan Machine Learning dengan Python

Materi belajar berbahasa Indonesia untuk memahami alur kerja *data mining* dan *machine learning*: dari mendefinisikan masalah, menyiapkan data, membangun model, hingga mengevaluasi dan mengoptimalkannya, dengan Python dan scikit-learn.

!!! info "Status"
    Seluruh bab sudah tersedia. Contoh kode dijalankan dengan Python 3.14 dan scikit-learn 1.9; keluaran yang ditampilkan berasal dari program yang benar-benar dijalankan. Data bersifat publik (bawaan scikit-learn dan statsmodels) atau **sintetis**, dan selalu diberi tanda.

## Isi tiap bab

- [Dasar-dasar](fundamentals/index.md): 12 pelajaran (lingkungan, NumPy, pandas, visualisasi, statistik, EDA, praproses, rekayasa fitur, pembagian data, metrik, *pipeline*, *overfitting* dan kebocoran data).
- [Klasifikasi](classification/index.md): 14 pelajaran, dari alur kerja sampai proyek prediksi churn.
- [Estimasi (Regresi)](estimation/index.md): 9 pelajaran, dari regresi linear sampai proyek harga rumah.
- [Forecasting](forecasting/index.md): 11 pelajaran, dari komponen deret waktu sampai proyek penjualan bulanan.
- [Klaster](clustering/index.md): 10 pelajaran, dari k-Means sampai proyek segmentasi pelanggan.
- [Aturan Asosiasi](association/index.md): 6 pelajaran, dari data transaksi sampai proyek keranjang belanja.

## Cara memakai materi ini

1. Siapkan [lingkungan Python](resources/python-environment.md).
2. Pelajari [Dasar-dasar](fundamentals/index.md) satu kali; semua bab merujuk ke sana.
3. Pilih bab sesuai kebutuhan. Setiap halaman bab memuat prasyarat, tujuan, dan rencana pelajaran.
4. Jalankan kode sendiri dan kerjakan latihannya.
