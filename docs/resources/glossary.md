# Glosarium

Istilah yang dipakai di seluruh materi. Istilah Inggris dipertahankan bila lazim dipakai. Daftar akan bertambah seiring pelajaran.

| Istilah | Padanan / arti singkat |
|---|---|
| *Feature* (fitur) | Variabel masukan yang menjelaskan sebuah data |
| *Target* / *label* | Nilai yang ingin diprediksi (kelas atau angka) |
| *Supervised learning* | Belajar dari data berlabel |
| *Unsupervised learning* | Belajar menemukan pola tanpa label |
| *Training set* (data latih) | Data untuk melatih model |
| *Validation set* (data validasi) | Data untuk memilih model atau hyperparameter |
| *Test set* (data uji) | Data untuk evaluasi akhir, dipakai sekali |
| *Cross-validation* (validasi silang) | Evaluasi berulang pada beberapa pembagian data |
| *Overfitting* | Model menghafal data latih dan buruk pada data baru |
| *Underfitting* | Model terlalu sederhana sehingga buruk di semua data |
| *Data leakage* (kebocoran data) | Informasi dari luar data latih ikut memengaruhi pelatihan |
| *Baseline* | Model sederhana sebagai pembanding minimum |
| *Hyperparameter* | Pengaturan model yang ditetapkan sebelum pelatihan |
| *Pipeline* | Rangkaian praproses dan model yang dijalankan berurutan |
| *Confusion matrix* | Tabel prediksi benar dan salah per kelas |
| *Precision*, *recall*, F1 | Metrik klasifikasi berbasis prediksi positif |
| *Residual* | Selisih nilai sebenarnya dan prediksi |
| *Seasonality* (musiman) | Pola berulang pada periode tetap |
| *Support*, *confidence*, *lift* | Ukuran kekuatan aturan asosiasi |
| *Cluster* (klaster) | Kelompok data yang mirip |
| *Regularization* (regularisasi) | Penalti pada besar koefisien untuk mengurangi *overfitting* |
| *Hyperparameter* tuning | Pencarian pengaturan model terbaik dengan validasi silang |
| ROC-AUC, PR-AUC | Ukuran kemampuan mengurutkan positif di atas negatif, tanpa ambang |
| MAE, RMSE, R² | Metrik regresi: galat rata-rata, akar galat kuadrat, proporsi variasi dijelaskan |
| *Horizon* | Berapa langkah ke depan yang diprediksi pada forecasting |
| *Rolling origin* | Evaluasi forecasting berulang dari beberapa titik asal |
| MASE | Galat forecasting relatif terhadap *baseline* seasonal naive |
| *Lag* | Nilai deret pada waktu sebelumnya, dipakai sebagai fitur |
| *Silhouette* | Metrik internal klaster: kedekatan ke klaster sendiri vs klaster lain |
| ARI | *Adjusted Rand Index*: kecocokan klaster dengan label acuan |
| *Itemset* | Himpunan barang pada aturan asosiasi |
| *Lift* | Rasio kemunculan bersama dibanding kebetulan statistik |
