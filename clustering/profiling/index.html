    Profil dan Interpretasi Klaster¶

    Tujuan pembelajaran¶

    • Membangun pipeline klastering (transformasi log, scaling, k-Means).
    • Membuat profil klaster dalam satuan asli dan indeks terhadap rata-rata.
    • Menamai segmen secara bermakna dan memeriksa kecocokannya.

    Mengapa profil?¶

    Klaster hanya berupa nomor. Nilainya baru muncul setelah ditafsirkan: apa yang membedakan satu klaster dari yang lain, dalam satuan yang dimengerti pemangku kepentingan. Alur: klasterkan pada data terskala, lalu profilkan pada satuan asli.

    Implementasi langkah demi langkah¶

    Data pelanggan sintetis (penjelasan): 600 pelanggan, lima fitur. annual_spend dan recency_days miring ke kanan sehingga diberi transformasi log1p sebelum standardisasi. Penamaan segmen di bawah memakai aturan dari profil; nama akhir selalu keputusan manusia. Program examples/clustering/profiling.py; program lengkap ada di akhir bagian ini.

    df = make_customer_segments()
features = ["annual_spend", "visits_per_month", "avg_basket", "recency_days", "age"]
skewed = ["annual_spend", "recency_days"]  # miring ke kanan -> log

# 1. Pipeline: log pada fitur miring, standardisasi, k-Means (k=4)
prep = ColumnTransformer(
    [("log", FunctionTransformer(np.log1p), skewed)],
    remainder="passthrough",
)
pipe = Pipeline([("prep", prep), ("scale", StandardScaler()),
                 ("km", KMeans(n_clusters=4, n_init=10, random_state=SEED))])
pipe.fit(df[features])
labels = pipe.named_steps["km"].labels_
Zt = pipe[:-1].transform(df[features])
print("silhouette: %.3f | ARI terhadap kelompok sebenarnya: %.3f" % (
    silhouette_score(Zt, labels), adjusted_rand_score(df["segment_true"], labels)))
    Kode Penjelasan
    skewed = ["annual_spend", "recency_days"] Fitur miring ke kanan yang perlu log.
    ColumnTransformer([("log", FunctionTransformer(np.log1p), skewed)], remainder="passthrough") Menerapkan np.log1p hanya pada kolom skewed; remainder="passthrough" meneruskan kolom lain apa adanya. (Urutan kolom keluaran: kolom log dulu, lalu sisanya.)
    Pipeline([("prep", prep), ("scale", StandardScaler()), ("km", KMeans(...))]) Tiga langkah berurutan; langkah terakhir adalah model.
    pipe.fit(df[features]) Melatih seluruh pipeline; tanpa y.
    pipe.named_steps["km"].labels_ Label klaster hasil k-Means (ambil langkah km menurut namanya).
    pipe[:-1].transform(df[features]) Menerapkan semua langkah kecuali yang terakhir ([:-1]), menghasilkan data terskala untuk menghitung silhouette. 
    silhouette: 0.428 | ARI terhadap kelompok sebenarnya: 0.927

    Hasil. Silhouette 0,428 dan ARI terhadap kelompok sebenarnya 0,927 (hanya dapat dihitung karena data sintetis).

    # 4. Penamaan berbasis aturan dari profil (nama sebenarnya diputuskan manusia)
names = {}
remaining = set(profile.index)
inactive = profile.loc[list(remaining), "recency_days"].idxmax(); names[inactive] = "tidak aktif"; remaining.discard(inactive)
loyal = profile.loc[list(remaining), "annual_spend"].idxmax(); names[loyal] = "loyal"; remaining.discard(loyal)
bargain = profile.loc[list(remaining), "visits_per_month"].idxmax(); names[bargain] = "pemburu diskon"; remaining.discard(bargain)
names[remaining.pop()] = "musiman"
print("\nNama segmen:", {int(k): v for k, v in sorted(names.items())})

    Penamaan berbasis aturan: klaster dengan recency_days terbesar dinamai "tidak aktif"; dari sisanya, annual_spend terbesar = "loyal"; lalu visits_per_month terbesar = "pemburu diskon"; sisanya "musiman". idxmax() memberi nomor klaster dengan nilai terbesar, dan remaining.discard(...) mengeluarkannya dari kandidat.

    Nama segmen: {0: 'musiman', 1: 'loyal', 2: 'tidak aktif', 3: 'pemburu diskon'}

    Hasil. Klaster 1 "loyal", 3 "pemburu diskon", 0 "musiman", 2 "tidak aktif". Nama hanyalah hipotesis dari profil, bukan fakta; uji dengan pemangku kepentingan.

    from pathlib import Path

import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
from sklearn.cluster import KMeans
from sklearn.compose import ColumnTransformer
from sklearn.metrics import adjusted_rand_score, silhouette_score
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import FunctionTransformer, StandardScaler

from segment_data import make_customer_segments

SEED = 42
OUT = Path("docs/assets/img/clustering")
OUT.mkdir(parents=True, exist_ok=True)

df = make_customer_segments()
features = ["annual_spend", "visits_per_month", "avg_basket", "recency_days", "age"]
skewed = ["annual_spend", "recency_days"]  # miring ke kanan -> log

# 1. Pipeline: log pada fitur miring, standardisasi, k-Means (k=4)
prep = ColumnTransformer(
    [("log", FunctionTransformer(np.log1p), skewed)],
    remainder="passthrough",
)
pipe = Pipeline([("prep", prep), ("scale", StandardScaler()),
                 ("km", KMeans(n_clusters=4, n_init=10, random_state=SEED))])
pipe.fit(df[features])
labels = pipe.named_steps["km"].labels_
Zt = pipe[:-1].transform(df[features])
print("silhouette: %.3f | ARI terhadap kelompok sebenarnya: %.3f" % (
    silhouette_score(Zt, labels), adjusted_rand_score(df["segment_true"], labels)))

# 2. Profil klaster dalam satuan ASLI
df["cluster"] = labels
profile = df.groupby("cluster")[features].mean().round(1)
profile.insert(0, "n", df.groupby("cluster").size())
profile.insert(1, "n%", (profile["n"] / len(df) * 100).round(0))
print("\nProfil klaster (rata-rata):\n", profile.to_string())

# 3. Indeks terhadap rata-rata keseluruhan (100 = rata-rata semua pelanggan)
index = (profile[features] / df[features].mean() * 100).round(0).astype(int)
print("\nIndeks terhadap rata-rata keseluruhan:\n", index.to_string())

# 4. Penamaan berbasis aturan dari profil (nama sebenarnya diputuskan manusia)
names = {}
remaining = set(profile.index)
inactive = profile.loc[list(remaining), "recency_days"].idxmax(); names[inactive] = "tidak aktif"; remaining.discard(inactive)
loyal = profile.loc[list(remaining), "annual_spend"].idxmax(); names[loyal] = "loyal"; remaining.discard(loyal)
bargain = profile.loc[list(remaining), "visits_per_month"].idxmax(); names[bargain] = "pemburu diskon"; remaining.discard(bargain)
names[remaining.pop()] = "musiman"
print("\nNama segmen:", {int(k): v for k, v in sorted(names.items())})

# 5. Kesesuaian dengan kelompok sebenarnya (hanya mungkin pada data sintetis)
print("\nCrosstab klaster vs kelompok sebenarnya:")
print(pd.crosstab(df["cluster"].map(names), df["segment_true"]).to_string())

# 6. Gambar
fig, ax = plt.subplots(figsize=(6.5, 4.2))
sc = ax.scatter(df["visits_per_month"], df["annual_spend"], c=df["cluster"], cmap="viridis", s=14)
ax.set(xlabel="kunjungan per bulan", ylabel="belanja tahunan (juta Rp)", yscale="log", title="Segmen pelanggan")
fig.tight_layout()
fig.savefig(OUT / "segments.png", dpi=130)
print("\nGambar tersimpan:", (OUT / "segments.png").as_posix())

    Kesalahan umum¶

    Hindari

    • Memprofilkan pada data terskala sehingga tidak dapat dibaca stakeholder.
    • Menganggap nama segmen sebagai kebenaran.
    • Mengabaikan ukuran klaster (klaster sangat kecil mungkin hanya outlier).
    • Menafsirkan perbedaan kecil antar-klaster sebagai bermakna tanpa uji.
    • Melupakan transformasi log pada fitur miring.

    Latihan¶

    1. Tambahkan median dan IQR tiap fitur ke profil. Apakah ada klaster dengan sebaran sangat lebar?
    2. Ulangi tanpa transformasi log. Bagaimana silhouette dan ARI berubah?
    3. Beri nama alternatif untuk klaster 3 dan jelaskan mengapa nama Anda cocok.

    Ringkasan¶

    Klasterkan pada data terskala dan transformasi, tafsirkan pada satuan asli dengan indeks terhadap rata-rata, beri nama sebagai hipotesis, dan pastikan tiap segmen membawa tindakan yang berbeda.
